# classic-game

スーファミ風の小さな横スクロールゲームです。外部ライブラリや画像ファイルを使わず、Canvas APIだけで背景・キャラクター・アニメーションを描画しています。

## 操作

- 画面左側を押し続ける: 左へ走る
- 画面右側を押し続ける: 右へ走る
- ダブルタップ: ジャンプ
- PCでは左右キーまたは A / D、ジャンプは Space / ↑

## GitHub Pages

PRをマージ後、リポジトリの **Settings → Pages** で次のように設定します。

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

公開URLは通常 `https://ishiishikou.github.io/classic-game/` です。
